Thể tích bể điều hòa CHỌN: m³
• Lượng_đã_xử_lý = Q_hr × T_xả ; Phần_dư = Q_day - Lượng_đã_xử_lý ; V_tính = Phần_dư × SF ; RT_thực = V_eq_sel / Q_hr (Chuẩn: 6 – 12 giờ)
• Khi xả đều 24/24h (Phần_dư ≤ 0), thực tế vẫn cần bể đệm điều hòa lưu lượng/nồng độ theo HRT đệm (Q_hr × HRT_đệm × SF) hoặc nhập trực tiếp V_eq_sel.

3. Bể thiếu khí khử Nitrat (Anoxic Tank)

V chọn = 19.0 m³
Hiệu suất H: 0.625
Rn (ROUND): 0.70 → 0.7
KDT (ROUNDUP): 0.074
VD1 tính toán: 17.13 m³
RT danh nghĩa: 7.92 giờ

Tuần hoàn nội bộ (Rn_sel × Q_hr): 1.68 m³/h
Thể tích bể Anoxic CHỌN (VD1_sel): m³
• H = (TNI - TNO) / TNI ; Rn = ROUND((H + (H - 1)×R)/(1 - H), 2) ; Rn_sel = ROUNDUP(Rn, 1)
• KDT = ROUNDUP(KD15 × STAN^(T_anox - 15), 3) ; VD1 = [(TNI×Q_day×10×H)/(KDT×MLVSS×10)] + [((1+R+Rn_sel)×Q_day×15)/(TS×60)]
• VD1_sel = ROUNDUP(VD1 × SF, 0) ; CMT = ROUNDUP(((3×TNI - BODI×0.7)×Q_day/1000), 1) ; RT_anox = VD1_sel / Q_hr (Chuẩn: 6 – 10 giờ)

Thể tích bể Oxic CHỌN (VN_sel): m³
• 4.1 Nitrat hóa: KNT = ROUNDUP(KN15 × STAN_ox^(T_ox - 15), 3) ; VN1 = ROUNDUP((TKN×Q_day×1e-3)/(KNT×MLVSS×1e-3), 2) ; VN1_sel = ROUNDUP(VN1×SF, 0)
• 4.2 Tuổi bùn: B = ROUNDUP(0.05 × 1.042^(T_b - 20), 3) ; W1 = A×BODI×Q_day/1000 ; W2 = B×MLVSS×Q_day/1000 ; W3 = 0.15×CMT + SSI×Q_day/1000
• VN2 = ROUNDUP(((W1 - W2 + W3)×SRT×1000/MLVSS), 2) ; VN2_sel = ROUNDUP(VN2×SF, 1) ; VN_sel = MAX(VN1_sel, VN2_sel) ; RT_oxic = VN_sel / Q_hr (Chuẩn: 7 – 12 giờ)
